Every lab follows the same loop
1. ARCHITECT
What problem does this mechanism solve?

2. VISUALIZE
Draw the complete flow.

3. PREDICT
What should happen and why?

4. IMPLEMENT
Build the smallest working version.

5. BREAK
Create one controlled failure.

6. DEBUG
Use logs, tests, state, and runtime evidence.

7. EXPLAIN
Trace the mechanism aloud.

8. REBUILD
Recreate the central part without looking.

9. WRITE
Document what changed in your understanding.
