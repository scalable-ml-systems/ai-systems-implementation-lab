# Total Labs
===============

Exercises under each lab
Lab 1 — Fundamentals
1. Count requests using dictionaries.
2. Count HTTP errors.
3. Calculate latency statistics.
4. Read JSONL files.
5. Generate and process 10,000 records.
DSA: Frequency counting; single-pass aggregation.

Lab 2 — Production Python Design
1. Write reusable functions.
2. Organize code into modules.
3. Add type hints and input validation.
4. Handle exceptions and malformed records.
5. Write pytest tests, including empty-input tests.
DSA: Linear search; two pointers.

Lab 3 — HTTP Client
1. Make HTTP GET requests.
2. Parse and validate responses.
3. Handle HTTP errors.
4. Implement timeouts.
5. Implement bounded retries.
DSA: Binary search; merging sorted lists.

Lab 4 — SQLite
1. Create database tables.
2. Insert request records.
3. Query by service and status.
4. Filter by timestamp range.
5. Implement transactions and rollback.
DSA: Hash lookup versus linear search; sorting.

Lab 5 — Async Python
1. Understand coroutines and await.
2. Make asynchronous HTTP requests.
3. Execute requests concurrently.
4. Limit concurrency using semaphores.
5. Handle failures and cancellation.
DSA: Queues; sliding window.

Lab 6 — Production Readiness
1. Create pyproject.toml.
2. Build a command-line interface.
3. Add structured application logging.
4. Profile performance using cProfile.
5. Perform an intentional failure test and document the utility.
DSA: Big-O analysis; bottleneck analysis.
