I experimentally compared `cudaMemcpyAsync()` using pageable and pinned host memory.

With pageable host memory, the API call took approximately **94 ms** and returned only when the transfer was nearly complete.

With pinned host memory, the API returned in approximately **7 µs**, while the DMA transfer continued for about **20 ms**.

This demonstrates that pinned host memory enables the host to enqueue an asynchronous transfer and continue executing while the GPU DMA engine performs the data movement.
